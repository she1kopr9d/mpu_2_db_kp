## Формулировка задания

**Информационная система для распределения учебной нагрузки на кафедре:**

- На кафедре учебного заведения распределяется нагрузка между преподавателями.

- О каждом преподавателе известны анкетные данные и сведения об ученой степени, занимаемой административной должности и стаже работы.

- Кафедра должна обеспечить проведение занятий по некоторым предметам. Для занятий по каждому предмету (с учетом вида занятий) устанавливается определенное количество часов.

- В результате распределения нагрузки определяется, какой преподаватель с какими группами и сколько занятий работает.

- Информация о распределенной нагрузке хранится несколько лет.
